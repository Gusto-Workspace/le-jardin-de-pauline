# Le Jardin de Pauline

Site vitrine Next.js connecté à l'API publique Gusto Manager.

## Développement

1. Copier `.env.example` vers `.env.local` et renseigner les variables.
2. Lancer l'API Gusto Manager sur le port `8012`.
3. Installer puis lancer le client : `npm install` et `npm run dev`.

Le restaurant de développement est centralisé dans `NEXT_PUBLIC_RESTAURANT_ID`.
